Use the following template to guide the creation of the PRD. Once it is complete, and both the user (them) and the model (you) are 1. satisfied that the requirements are defined well enough AND 2. share the same understanding of the requirements, write the document to the project's `docs/` directory.

```markdown
# Project Title

This is a Project Requirements Document for `Project Title`.

## Description

What is it?

## Problem

What problem is this solving?

## Why

How do we know this is a real problem worth solving?

## Success

How do we know if we've solved this problem?

## Audience

Who are we building for?

## What

Roughly, what does this look like?

## How

What is the experiment plan?

## When

When does it ship and what are the milestones?
```
